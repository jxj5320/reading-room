음성(TTS) 설정

새 목소리를 쓰려면: ElevenLabs에서 그 목소리 페이지 → "Add to my voices(내 보이스에 추가)" → "⋮" 메뉴나 상세페이지에서 Voice ID 복사 → 위 Voice ID 칸에 붙여넣고 이름을 붙여 "+ 저장"을 누르면 다음부터 "저장된 목소리" 목록에서 바로 고를 수 있어요. API Key는 ElevenLabs 사이트 오른쪽 위 프로필 → API Keys에서 발급받을 수 있어요.
키는 이 브라우저에 저장돼서 다시 들어와도 다시 입력할 필요 없어요. 이 기기를 다른 사람과 같이 쓰거나 분실 위험이 있다면 해당 서비스에서 키를 재발급/폐기하면 돼요.

저장된 목록

이 브라우저에서 직접 Amazon Polly API를 SigV4로 서명해 호출해서 실제 mp3 오디오와 단어별 타이밍(Speech Marks)을 받아와요. 영문 알파벳이 없는 토큰(한글, 숫자 목록, →, / 등)은 자동으로 읽지 않아요.
